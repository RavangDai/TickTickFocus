⏱️ TickTickFocus

A clean, minimal Pomodoro timer built with React, Tailwind, TypeScript, and Framer Motion, featuring dark/light mode, PWA support, keyboard shortcuts, and 7-day focus history.

🌟 Features

Focus • Short Break • Long Break

Dark / Light theme

Smooth animations

Keyboard shortcuts (Space = start/pause, R = reset)

7-day session history

Installable PWA (works offline)

🛠️ Tech

React + Vite + TypeScript • TailwindCSS • Framer Motion • Vite-PWA plugin

🚀 Run locally
npm install
npm run dev

📦 Build
npm run build
